# bibibi_test

Повне тестування ноутбука одним скриптом: Windows 10/11, Linux, macOS.
Близько 15 хвилин автоматичних тестів, потім ручні тести в браузері і фінальний звіт на робочому столі.

## Запуск

### Windows 10 / 11

**Варіант 1.** Скачати `bibibi_test.bat` і запустити подвійним кліком. Він сам попросить права адміністратора. Якщо поруч немає `bibibi_test.ps1`, він скачає його з цієї репи і видалить після тесту.

**Варіант 2.** Відкрити PowerShell від імені адміністратора і вставити:

```powershell
[Net.ServicePointManager]::SecurityProtocol='Tls12'; & ([scriptblock]::Create((irm https://raw.githubusercontent.com/w00o-o00w/bibibi_test/main/bibibi_test.ps1).TrimStart([char]0xFEFF)))
```

### Linux і macOS

Відкрити термінал і вставити:

```bash
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/w00o-o00w/bibibi_test/main/bibibi_test.sh)"
```

**Mac, у користувача немає прав адміністратора:** у терміналі на його робочому столі виконати `su <адмін>`, ввести пароль адміна, потім команду вище. Звіт ляже на робочий стіл того, хто залогінений на екрані, а не адміна. Якщо macOS спитає дозвіл терміналу на доступ до «Робочого столу» чи «Завантажень», треба дозволити.

## Як іде тест

1. Автоматичні тести в консолі (~15 хв). Кожен тест окремий: має свій ліміт часу, помилка чи зависання одного не зупиняє інші.
   - **Ctrl+C** — пропустити поточний тест
   - **Ctrl+C двічі за 2 с** — перервати все (звіт однаково буде)
2. Проміжний звіт зберігається на робочий стіл.
3. Сам відкривається браузер з ручними тестами: екран, динаміки, клавіатура, тачпад. Після кожного тесту: «Працює», «Проблема» (можна з коментарем) або «Пропустити».
4. Кнопка «Зберегти звіт». Скрипт сам переносить файл із «Завантажень» на робочий стіл замість проміжного.

## Що перевіряється

| | Windows | Linux | macOS |
|---|---|---|---|
| Модель, серійник, BIOS/прошивка, ОС | ✓ | ✓ | ✓ |
| Активація Windows, Secure Boot, TPM | ✓ | TPM | SIP, блокування активації |
| Процесор, пам'ять, відеокарта, дисплей | ✓ | ✓ | ✓ |
| Диски: стан SMART, знос, температура, помилки | ✓ | ✓ | стан SMART |
| Батарея: знос, цикли, зарядка | ✓ | ✓ | ✓ |
| Wi-Fi, Ethernet, Bluetooth | ✓ | ✓ | ✓ |
| Камера, звук, мікрофон, тачпад, USB | ✓ | ✓ | ✓ |
| Драйвери з помилками | ✓ | ✓ | — |
| Журнал: сині екрани, апаратні помилки, збої диска | ✓ | ✓ | kernel panic |
| Навантаження CPU 5 хв: троттлінг, температура | ✓ | ✓ | троттлінг |
| Швидкість запису і читання диска (2 ГБ) | ✓ | ✓ | ✓ |

## Звіт

Файл на робочому столі: `НазваПК - SN серійник - дата.html`. Якщо той самий ноут тестується вдруге за день, додається час.

- 🔴 **Критично**: несправність
- 🟠 **Зауваження**: працює, але є проблеми
- 🟢 **Норма**
- ⚪ **Не вдалося перевірити**: окремо, з причиною
- Повні характеристики внизу

## Безпека

- Нічого не відправляється в інтернет. Звіт лишається тільки на ПК.
- Особисті файли не читаються, налаштування системи не змінюються, камера й мікрофон не вмикаються.
- На диск пишеться лише тимчасовий файл для тесту швидкості (одразу видаляється) і сам звіт.
- **Linux:** якщо бракує `smartmontools`, `dmidecode`, `pciutils`, `usbutils`, вони ставляться з офіційного репозиторію дистрибутива. Скрипт запам'ятовує, що саме поставив (разом із залежностями), і в кінці видаляє **рівно це**, навіть якщо тест перервали. Те, що стояло до тесту, не чіпається.
- **Windows і macOS:** нічого не встановлюється.

## Параметри (необов'язкові)

- Windows (з консолі, вже відкритої від адміністратора): `bibibi_test.bat -CpuSeconds 600 -DiskTestMB 4096 -NoBrowser`
- Linux / macOS: `sudo bash bibibi_test.sh --cpu-seconds 600 --disk-mb 4096 --no-browser`
